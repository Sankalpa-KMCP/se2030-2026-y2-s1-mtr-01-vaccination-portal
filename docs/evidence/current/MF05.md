# MF05 — Administration, Drafts and Certificates

WBVP-SE2030; canonical business reference 3.3-AI / 2026-08-14-R9. Current implementation: `origin/develop` at `444364d4b742fa08455c4acf0538baa836e9529a` (2026-10-07 audit).

## 1. Function scope

Administration, Drafts and Certificates. Classification: VERIFIED_FINAL_BY_USER_CONSTRAINT. Exactly five assessed functions; shared capabilities remain supporting evidence.

## 2. Actors/roles

Vaccinator; Citizen for own history/certificates; Admin for permitted correction/certificate actions; public certificate verifier. SUPER_ADMIN exclusion exists on several clinical controllers.

## 3. Primary workflow

Prepare and edit an unfinalized draft; confirm physical administration; finalize with record/stock/appointment/certificate changes in one transaction; view history, corrections and certificate lifecycle.

## 4. Key business rules

Finalization requires a valid draft, checked-in appointment and compatible available batch. A unique record prevents duplicate completion. Certificate lifecycle includes revocation/reissue; a record can have multiple historical issues.
