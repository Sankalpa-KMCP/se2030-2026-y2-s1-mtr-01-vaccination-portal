# Current endpoint inventory

Baseline: origin/develop `444364d4b742fa08455c4acf0538baa836e9529a`, inspected 2026-10-07. This inventory extracts current REST controller mappings and signatures. It includes aliases, but not Actuator/internal framework routes. Request DTOs do not describe path/query parameters; inspect the linked method for those. Authorization annotations are literal method/class expectations, not substitutes for the filter chain and service ownership checks.

The [OpenAPI document](openapi.yaml) deliberately models only the ten AuthController operations; other DTO schemas are omitted rather than invented. Shared authentication, profiles, analytics and assistant are supporting functionality, not additional assessed functions.

## Significant errors and policy

Auth login/refresh: 400 malformed/validation, 401 invalid credentials/session, 403 disallowed account state, 423 locked. Registration: 400 validation/role, 409 duplicate email. Action-token verification/reset: 400 invalid/expired/used token. Forgot-password/resend return generic 200 even on caught delivery failure. OTP verification has 400 invalid/expired/attempt limit, 409 already verified and 429 cooldown. Auth /me can return an empty 401. Domain validation/conflict/not-found and ownership errors depend on the linked module exception handlers; this inventory does not assert uniform bodies/statuses for every route. Public certificate verification is annotated permitAll; inspect SecurityConfig as well as controller policy before treating an annotation as deployment proof.

Cookie login/refresh use HttpOnly, SameSite=Lax, Secure by default, /api/v1/auth path and seven-day lifetime. Logout clears compatible cookie attributes and returns 204 without requiring a JSON body. No raw refresh token is returned in JSON.
