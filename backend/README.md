# Backend

The backend application, REST APIs, authentication, authorization, business rules, and integrations will be maintained in this directory.

## Declared Technology Baseline

The canonical v3.3 project specification defines the backend baseline as:

- Java 21
- Spring Boot
- Maven

The application structure, dependencies, environment configuration, database connectivity, and development commands will be added when the backend foundation is initialized through an approved project issue and pull request.

Do not add generated dependencies, compiled output, environment secrets, real personal or medical data, real vaccination records, or unrelated files to this directory.
