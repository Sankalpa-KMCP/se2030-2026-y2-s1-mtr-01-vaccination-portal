# Frontend

The frontend application will be maintained in this directory.

## Declared Technology Baseline

The canonical v3.3 project specification defines the frontend baseline as:

- React
- Vite
- Bootstrap 5

The application structure, dependencies, environment configuration, and development commands will be added when the frontend foundation is initialized through an approved project issue and pull request.

Do not add generated dependencies, build output, environment secrets, real personal or medical data, or unrelated files to this directory.
